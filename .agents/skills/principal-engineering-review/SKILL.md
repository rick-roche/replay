---
name: principal-engineering-review
description: Provide pragmatic engineering review for design, delivery risk, and long-term maintainability.
---

1. State assumptions, constraints, risks, and viable options clearly.
2. Prefer the smallest design consistent with repository patterns and YAGNI. Ask before architectural changes.
3. Identify specific quality, security, operational, and testing gaps with practical mitigations.
4. Propose follow-up work or an issue description when useful; do not create external issues without authorization.
