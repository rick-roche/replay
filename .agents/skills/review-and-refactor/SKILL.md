name: review-and-refactor
description: Review a requested diff or scope for correctness, maintainability, and tests.
---

1. Read `AGENTS.md` and only the development guidance relevant to the requested scope.
2. Review the requested files or current diff. Prioritize correctness, regressions, security, API contracts, and missing tests.
3. Report findings first with file references. Do not refactor during a review-only request.
4. If asked to make changes, keep them focused and run applicable validation.
