---
name: create-epic
description: Create a well-scoped epic and testable user stories for Re:Play.
---

1. Read `AGENTS.md`, `specs/feature-spec.md`, `specs/user-stories.md`, and `specs/todo.md`.
2. Ask concise questions for unclear product scope before changing documentation.
3. Define the epic's goal, boundaries, and measurable user value.
4. Break it into independently testable user stories with clear acceptance criteria.
5. Update the specification, stories, and todo checklist consistently.
